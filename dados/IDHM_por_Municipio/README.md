## Dicionário de Dados (`IDHM_por_Municipio_AM`)

Tabela contendo os dados do Índice de Desenvolvimento Humano Municipal (IDHM) referentes ao ano de 2010 para os municípios do Estado do Amazonas e o comparativo com a média nacional (Brasil).

| Variável | Tipo | Descrição | Exemplo / Valores |
| :--- | :--- | :--- | :--- |
| `Territorialidades` | Texto | Nome do município do Amazonas (acompanhado da sigla `AM`) ou o indicador nacional (`Brasil`). | `Manaus (AM)`, `Alvarães (AM)`, `Brasil` |
| `IDHM 2010` | Numérico (Float) | Índice de Desenvolvimento Humano Municipal registrado no Censo de 2010. Varia de `0,000` a `1,000`. | `0.737` (Manaus), `0.450` (Atalaia do Norte) |
