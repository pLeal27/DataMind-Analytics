### Localização dos Municípios (`localização_municipios_amazonas.ods`)

| Variável | Tipo | Descrição | Exemplo / Valores |
| :--- | :--- | :--- | :--- |
| `codigo_ibge` | Numérico (Inteiro) | Código IBGE do município. | `1300029` (Alvarães), `1302603` (Manaus)[cite: 4] |
| `nome` | Texto | Nome oficial do município. | `Alvarães`, `Manaus`[cite: 4] |
| `latitude` | Numérico (Float) | Coordenada geográfica de latitude da sede municipal. | `-3.22727`[cite: 4] |
| `longitude` | Numérico (Float) | Coordenada geográfica de longitude da sede municipal. | `-64.8007`[cite: 4] |
| `capital` | Binário (`0`/`1`) | Indica se o município é a capital do Estado (`1`: Sim, `0`: Não). | `0` ou `1`[cite: 4] |
| `codigo_uf` | Numérico (Inteiro) | Código IBGE do Estado (`13` para o Amazonas). | `13`[cite: 4] |
| `siafi_id` | Numérico (Inteiro) | Código de identificação do município no Sistema SIAFI. | `289`[cite: 4] |
| `ddd` | Numérico (Inteiro) | Código DDD telefónico da região. | `92`, `97`[cite: 4] |
| `fuso_horario` | Texto | Fuso horário oficial do município. | `America/Porto_Velho`, `America/Rio_Branco`[cite: 4] |
