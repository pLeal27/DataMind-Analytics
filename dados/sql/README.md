# Scripts SQL

Esta pasta contém os scripts SQL utilizados no projeto DataMind-Analytics.

## Arquivos

- `DIM_CALENDARIO_INSERTS.sql`: script com comandos `INSERT` para popular a dimensão calendário, considerando os anos de 2014, 2018, 2022 e 2026.

## Observação

Antes de executar o script no banco de dados, confirmar com a equipe se a coluna `DIA` representa o dia sequencial do ano (de 1 a 365 ou 366 nos anos bissextos).
