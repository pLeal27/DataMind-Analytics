## Dicionário de Dados (`MOTIVO_CASSACAO`)

| Variável | Descrição |
| :--- | :--- |
| `DT_GERACAO` | Data da extração dos dados para geração do arquivo[cite: 2]. |
| `HH_GERACAO` | Hora da extração dos dados com base no horário de Brasília[cite: 2]. |
| `ANO_ELEICAO` | Ano de referência da eleição[cite: 2]. Para eleições suplementares, mantém-se o ano da eleição ordinária correspondente[cite: 2]. |
| `CD_TIPO_ELEICAO` | Código do tipo de eleição (`1`: Suplementar, `2`: Ordinária, `3`: Consulta Popular)[cite: 2]. |
| `NM_TIPO_ELEICAO` | Nome do tipo de eleição (Ordinária, Suplementar ou Consulta Popular - Plebiscito/Referendo)[cite: 2]. |
| `CD_ELEICAO` | Código único da eleição no âmbito da Justiça Eleitoral (único por eleição e por turno)[cite: 2]. |
| `DS_ELEICAO` | Descrição da eleição[cite: 2]. |
| `SG_UF` | Sigla da Unidade da Federação em que ocorreu a eleição[cite: 2]. |
| `SG_UE` | Sigla da Unidade Eleitoral onde o candidato concorre (`BR` para abrangência federal; sigla da UF para estadual; código do município para municipal)[cite: 2]. |
| `NM_UE` | Nome da Unidade Eleitoral ("Brasil" para abrangência nacional, nome da UF para estadual ou nome do município para municipal)[cite: 2]. |
| `SQ_CANDIDATO` | Número sequencial do candidato, gerado internamente pelos sistemas eleitorais (não é o número de campanha)[cite: 2]. |
| `DS_MOTIVO_CASSACAO` | Motivo da cassação do pedido de candidatura pela Justiça Eleitoral[cite: 2]. |
