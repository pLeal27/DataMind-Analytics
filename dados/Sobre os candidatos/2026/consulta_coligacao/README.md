# Dicionário de Dados - Consulta Coligação (`CONSULTA COLIGACAO`)

| Variável | Descrição |
| :--- | :--- |
| `DT_GERACAO` | Data da extração dos dados para geração do arquivo. |
| `HH_GERACAO` | Hora da extração dos dados para geração do arquivo com base no horário de Brasília. |
| `ANO_ELEICAO` | Ano de referência da eleição para geração do arquivo. **Obs:** para eleições suplementares, é o ano da eleição ordinária correspondente. |
| `CD_TIPO_ELEICAO` | Código do tipo de eleição (1: Eleição Suplementar; 2: Eleição Ordinária; 3: Consulta Popular). |
| `NM_TIPO_ELEICAO` | Nome do tipo de eleição. |
| `NR_TURNO` | Número do turno da eleição. |
| `CD_ELEICAO` | Código único da eleição no âmbito da Justiça Eleitoral (único por eleição e por turno). |
| `DS_ELEICAO` | Descrição da eleição. |
| `DT_ELEICAO` | Data da ocorrência da eleição. |
| `SG_UF` | Sigla da unidade da federação na qual a candidata ou candidato concorre na eleição. |
| `SG_UE` | Sigla da unidade eleitoral na qual a candidata ou candidato concorre (UF, município ou BR para Presidente). |
| `NM_UE` | Nome da unidade eleitoral (Nome do município, UF ou "Brasil"). |
| `CD_CARGO` | Código do cargo ao qual a candidata ou candidato concorre. |
| `DS_CARGO` | Descrição do cargo ao qual a candidata ou candidato concorre. |
| `TP_AGREMIACAO` | Forma como concorre nas eleições (Coligação, Federação ou Partido Isolado). |
| `NR_PARTIDO` | Número do partido da candidata ou candidato. |
| `SG_PARTIDO` | Sigla do partido da candidata ou candidato. |
| `NM_PARTIDO` | Nome do partido da candidata ou candidato. |
| `NR_FEDERACAO` | Número da federação pela qual o partido concorre na eleição. |
| `NM_FEDERACAO` | Nome da federação pela qual o partido concorre na eleição. |
| `SG_FEDERACAO` | Sigla da federação pela qual o partido concorre na eleição. |
| `DS_COMPOSICAO_FEDERACAO` | Composição da federação (concatenação das siglas dos partidos federados intercaladas com "/"). |
| `SQ_COLIGACAO` | Sequencial da coligação pela qual o partido concorre na eleição. |
| `NM_COLIGACAO` | Nome da coligação pela qual o partido concorre na eleição. |
| `DS_COMPOSICAO_COLIGACAO` | Composição da coligação (concatenação das siglas dos partidos coligados intercaladas com "/"). |
| `CD_SITUACAO` | Código da situação da legenda. |
| `DS_SITUACAO` | Descrição da situação da legenda. |
| `NM_TIPO_DESTINACAO_VOTOS` | Nome do tipo da destinação dos votos. |
