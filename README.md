## Sobre o Projeto

Este repositório contém a solução desenvolvida pela equipe **DataMind-Analytics** para a análise estratégica dos **Dados Abertos de Votação do TSE (Tribunal Superior Eleitoral)** com foco no **Estado do Amazonas (AM)**.

O objetivo do projeto é transformar dados brutos de votação e perfil de eleitorado em um modelo de dados relacional e dimensional em SQL Server/T-SQL, alimentando dashboards interativos em Power BI para suporte à tomada de decisão de governos e candidatos.
